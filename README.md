## Установка

1. Скачайте DMG-файл.
2. Откройте его двойным щелчком.
3. Перетащите `AppReinstaller.app` в папку «Программы».
4. Установите Apple Configurator из Mac App Store.
5. В Apple Configurator один раз выберите **Install Automation Tools**.
6. Подключите iPhone, разблокируйте его и нажмите «Доверять».

Исходный код проекта хранится в отдельном приватном репозитории.
