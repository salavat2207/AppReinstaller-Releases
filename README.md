# AppReinstaller — готовое приложение

Актуальная версия приложения для macOS:

Выпуск 11.1.0 содержит backend авторизации `ipatool-cpp` для Apple Silicon
(arm64). Поддержка Intel Mac в этой экспериментальной версии пока не включена.

- [AppReinstaller-latest.dmg](https://github.com/salavat2207/AppReinstaller-Releases/raw/main/AppReinstaller-latest.dmg?v=latest)

## Установка

1. Скачайте DMG-файл.
2. Откройте его двойным щелчком.
3. Перетащите `AppReinstaller.app` в папку «Программы».
4. Установите Apple Configurator из Mac App Store.
5. В Apple Configurator один раз выберите **Install Automation Tools**.
6. Подключите iPhone, разблокируйте его и нажмите «Доверять».

### Если macOS сообщает о неизвестном разработчике

Релиз распространяется напрямую и не подписан сертификатом Developer ID и не
нотариализован Apple. Поэтому при первом запуске macOS может показать «Неизвестный
разработчик» или «Apple не может проверить приложение». Для файла, скачанного из
этого репозитория, используйте штатное разрешение запуска:

1. Откройте Finder → «Программы».
2. Нажмите по `AppReinstaller.app` правой кнопкой мыши (или удерживая Control) и
   выберите **Открыть**.
3. В диалоге подтверждения нажмите **Открыть** ещё раз.

Если приложение уже было заблокировано, откройте **Системные настройки →
Конфиденциальность и безопасность**, найдите сообщение о заблокированном
`AppReinstaller` и нажмите **Всё равно открыть**. При необходимости подтвердите
действие паролем пользователя Mac.

Не отключайте Gatekeeper полностью. Перед разрешением запуска проверьте, что DMG
скачан по ссылке выше, из официального репозитория релизов.

## Как пользоваться

### Первый запуск

При первом запуске приложение само проверяет, установлен ли Apple
Configurator и его утилита `cfgutil`. Если нет — вместо основного экрана
покажется пошаговая подсказка:

1. Установить Apple Configurator (кнопка ведёт в Mac App Store).
2. Один раз открыть Apple Configurator и выбрать в меню **Install
   Automation Tools** («Установить инструменты автоматизации»).
3. Подключить iPhone кабелем, разблокировать его и нажать «Доверять»,
   при необходимости ввести код-пароль устройства.
4. Нажать «Проверить снова» — приложение само определит инструмент и
   подключённый iPhone.

### Вход в Apple ID

Приложения устанавливаются от имени вашего Apple ID, поэтому нужен вход
в App Store. Нажмите «Выполните вход» в шапке приложения (или «Войти» на
вкладке «Приложения») — откроется окно входа:

1. Нажмите «Войти через Terminal». Откроется окно Terminal с уже
   запущенным безопасным сценарием входа.
2. Введите в Terminal свой Apple ID, пароль и код двухфакторной
   аутентификации — именно в этом окне, не в самом приложении.
3. Вернитесь в AppReinstaller и нажмите «Проверить вход».

Пароль и код 2FA нигде не сохраняются: они передаются напрямую системной
утилите Apple и не проходят через код самого приложения.

### Подключение iPhone

Список подключённых устройств виден в левой панели и на вкладке
«Устройство». Если iPhone не появляется — проверьте кабель, разблокируйте
экран и подтвердите «Доверять этому компьютеру» на самом устройстве.

### Установка приложений из каталога

На вкладке «Приложения»:

- Ищите нужное приложение через поле поиска (по названию или App ID).
- Переключайте вид между «Значки» и «Список».
- Клик по приложению открывает карточку с кнопкой «Установить на
  iPhone».
- Отметьте несколько приложений — появится кнопка «Установить
  выбранные», которая ставит их все по очереди на подключённый iPhone.

### Установка по App ID, ссылке или Bundle ID

Внизу вкладки «Приложения» есть поле «Установить приложение по App ID,
ссылке или Bundle ID» — подходит числовой App ID, ссылка на страницу в
App Store или bundle identifier. Введите значение и нажмите **Enter**
или кнопку «Установить по ID».

### Установка из уже скачанного .ipa файла

Если у вас уже есть `.ipa` файл на Маке (например, скачанный вручную),
не нужно искать его в App Store — на вкладке **«Файл IPA»**:

1. Перетащите `.ipa` файл в отмеченную область либо нажмите «Выбрать
   файл…» и укажите его через системное окно выбора.
2. Нажмите «Установить на iPhone».

Этот способ не требует входа в App Store — файл устанавливается
напрямую через Apple Configurator.

### История и диагностика

- Вкладка «История» показывает все попытки установки: название
  приложения, устройство, время и результат (успех/ошибка).
- Ссылка «Диагностика» внизу левой панели открывает подробный журнал
  действий приложения — полезно, если нужно разобраться в причине
  ошибки или переслать лог разработчику. Журнал никогда не содержит
  Apple ID, пароли, коды 2FA или токены сессии.

### Настройки

На вкладке «Настройки»:

- **Обновление** — показывает установленную версию, позволяет вручную
  проверить наличие новой версии и запустить её загрузку и установку
  прямо из приложения.
- Кнопка «Связаться с разработчиком» — обратная связь.

### Частые ошибки

- **«Сессия App Store отсутствует или истекла»** — войдите заново через
  «Войти через Terminal» → «Проверить вход».
- **«Apple не вернула доступный пакет для указанного приложения»** —
  приложение, скорее всего, снято с публикации в App Store для вашего
  региона или устройства; попробуйте установить его из уже скачанного
  `.ipa` файла на вкладке «Файл IPA».
- **«Устройство недоступно»** — iPhone на мгновение пропал по USB
  (например, сразу после предыдущей установки); проверьте кабель и
  повторите попытку.
- **«Apple не выдала лицензию на это приложение»** — приложение никогда
  не покупалось/не устанавливалось под этим Apple ID.

Исходный код проекта хранится в отдельном приватном репозитории.
